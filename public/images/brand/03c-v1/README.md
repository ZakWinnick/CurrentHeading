# Current Heading 03C v1

September 7, 2026 Soft Direction logo pack. SVG masters are copied without geometry changes from the maintained Current Heading workspace asset pack.

- `lockup-horizontal-light.svg`: ivory and red logo for the dark website header and footer.
- `avatar-symbol-dark.svg`: opaque charcoal avatar used to generate browser and home-screen icons.
- `mark-light.svg`: transparent ivory and red standalone symbol.

Palette: charcoal `#111314`, ivory `#F3F0E8`, red `#B52229`.

The site uses the vector lockup at its native aspect ratio. Root favicon files are rasterizations of the avatar master. The 1200 × 630 social card uses the same lockup and palette. Asset URLs in the page metadata carry `v=03c-v1` to refresh cached previews and icons.
